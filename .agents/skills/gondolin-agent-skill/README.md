# Gondolin Agent Skill

This folder contains a single `SKILL.md` that summarizes and operationalizes the official Gondolin documentation into an agent-ready skill.

Drop this folder into your agent's skills directory or copy the contents of `SKILL.md` into your agent skill registry.

Covered pages:

- Home
- Workloads and Lifecycle
- CLI
- Secrets Handling
- Ingress and Listening
- SSH
- Debug Logging
- SDK Overview
- SDK VM Control
- SDK Network Access
- SDK Storage Snapshots
- VFS Providers
- Snapshots
- Custom Images
- Architecture Overview
- Security Design
- Network Stack
- VM Backends: QEMU vs libkrun
- QEMU Backend
- Current Limitations
